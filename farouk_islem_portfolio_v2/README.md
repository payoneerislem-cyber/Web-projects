# Farouk Islem — Portfolio v2

واجهة عربية موجّهة لزوار الموقع والعملاء المحتملين، مبنية باستخدام Flask + Jinja + HTML/CSS + JavaScript.

## التشغيل
```bash
pip install flask
python app.py
```
ثم افتح `http://127.0.0.1:5000`.

## مهم قبل النشر
- عدّل البريد في `PROFILE["email"]` داخل `app.py`.
- أضف روابط حساباتك الحقيقية في `github`, `linkedin`, `instagram` و`whatsapp`. اترك القيمة فارغة إذا لم ترد عرضها.
- راجع النصوص لتتأكد أنها تصف خدماتك وخبرتك الحقيقية.
- استبدل المشاريع النموذجية بروابط ومعلومات مشاريع فعلية. لا تعرض الأمثلة على أنها أعمال مكتملة إذا لم تكن كذلك.
- الصورة الشخصية موجودة في `static/images/`.
- استعمل استضافة تدعم Flask وخادم WSGI للإنتاج؛ لا تستخدم `debug=True` في النشر العام.
