# Portfolio listing — NOOR Studio

## العربية
**NOOR Studio — نظام حجز مواعيد**

موقع ثنائي اللغة يعرض الخدمات والفريق، ويحسب الأوقات المتاحة بحسب مدة الخدمة والحجوزات الحالية، مع رابط خاص لمتابعة الطلب ولوحة إدارة لتأكيد المواعيد وتحديث حالاتها.

**التقنيات:** Python، Flask، SQLAlchemy، SQLite/PostgreSQL، HTML، CSS، JavaScript.

**مهم:** هذا مشروع تجريبي؛ الاستوديو والأسعار والأسماء والحجوزات افتراضية، وليست نشاطًا تجاريًا أو نتائج عملاء حقيقيين.

## English
**NOOR Studio — Appointment Booking System**

A bilingual booking website that calculates available time slots based on service duration and active appointments, with private booking references and an admin dashboard for appointment status management.

**Stack:** Python, Flask, SQLAlchemy, SQLite/PostgreSQL, HTML, CSS, JavaScript.

**Demo note:** Studio details, prices, team names and sample appointments are fictional portfolio data, not a real business or client results.
