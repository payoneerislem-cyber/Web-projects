# Portfolio listing — MADAR Services

## العربية
**مَدار — موقع شركة خدمات**

موقع ثنائي اللغة لشركة خدمات منزلية وتجارية، يتضمن عرض الخدمات، نموذج طلب عرض سعر، ولوحة إدارة لمتابعة الطلبات وتحديث حالاتها.

**التقنيات:** Python، Flask، SQLAlchemy، SQLite/PostgreSQL، HTML، CSS، JavaScript.

**مهم:** هذا مشروع تجريبي مستقل؛ أسماء الشركة والطلبات الموجودة بيانات افتراضية، وليست عميلًا حقيقيًا أو نتائج تجارية.

## English
**MADAR Services — Service Business Website**

A bilingual service-business website with a service catalogue, quote-request workflow, and private admin dashboard for managing incoming enquiries.

**Stack:** Python, Flask, SQLAlchemy, SQLite/PostgreSQL, HTML, CSS, JavaScript.

**Demo note:** This is a fictional portfolio project. Company details and sample enquiries are demo data, not a real client or business result.
